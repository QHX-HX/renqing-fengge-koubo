# 句式模板库（可填空）

> 生成文案时直接套用，不要每次重新想句式。`< >` 内为待填变量。

## 1. 黄金三秒开场钩

| 句式 | 示例 |
|---|---|
| 你从小到大，被人反复灌输的一句话是哪句？是这句——<信条>。 | 细节决定成败 |
| 今天我要把<一句话>，当着你的面，拆开给你看。 | 这句话 |
| 你有没有发现，身边<某类人>，往往是<反差结果>的那批人？ | 最努力的最焦虑 |
| <一个数字>年前没人告诉你的一个真相：<真相>。 | 30 |
| 说句得罪人的话——<反常识断言>。 | 群众的眼睛是瞎的 |
| 我接下来要讲的，是<某个群体>最不爱听的<数量>句话。 | 老实人 / 三句 |

## 2. 铁律断言句

- 第 N 条，你永远不要<用 A 掩盖 B>。
- 第 N 条，你永远不要在<错误维度>上拼命努力。
- 你记住一句话：<铁律>。
- 从今天起，<可执行动作>，这就是<概念>。

## 3. 三层问句

**自问自答（钉概念）**
- 为什么？因为<一句话机理>。
- 他是什么？他是个<比喻物件>。
- 这叫什么？这在<领域>里叫<术语>。

**反问扎心（逼停留）**
- 你是不是就这样？
- 你有没有发现，<扎心现象>？
- 你以为你在<做 A>，其实你在<做 B>？

**开放收尾（钓评论）**
- 现在你知道了吗？
- 你会怎么选？
- 换作是你，你会<接不接这通电话>？

## 4. 一物一喻句

- <抽象概念>，就像<日常物件>——<一句话点破策略>。
- 你以为你在<做 A>，其实你只是在<物件的荒诞行为>。（电梯里做俯卧撑）
- <概念>就是<物件>：<物件的运作逻辑 = 策略>。
- 记住，<物件>是<自己会怎样>的，你不用<多此一举的动作>。（烂桃子）

## 5. 数字铁律句

- <动作>，先等 <N 秒/分钟>。
- 你赚了 <X>，一定要<还/分>出 <Y>（<百分比>）。
- 一次 <大额行为>，不如 <N 次小额定频行为>。
- 方向偏 <1 度>，<距离>之后你偏了整整 <结果数字>。

## 6. 双轨读心句

- 他嘴上说<好听的 A>，心里想的是<难听的 B>。
- 他表面<客气动作>，潜台词是<真实意图>。
- 你以为这是<表面解读>，其实这是在<权力信号解读>。

## 7. 反直觉反转句

- <常识认知>？恰恰相反，<反转操作>。
- 你以为的最优解，恰恰是输的开始。
- 正确，从来不等于<成功>。
- 越<努力的动作>，越可能是在<制造更大的沉没成本>。

## 8. 留白句

- 这个我就不细说了，懂的都懂。
- 剩下的，你品。
- 为什么？评论区见。

## 9. 升华条句（末条）

- 改变<结果>的<N 大心法 / 几个层级>，上中下：上<A>，中<B>，下<C>。
- <数字>加<数字>等于什么？等于<拔高的结果>。
- 而真正<最关键的对象>是谁？其实只有一个——<反转金句>。

## 10. 金句收尾句

- 真正的问题，从来不是<表层>，而是——<金句>。
- 你不是输在<努力>，你是输在<维度>。
- 终极的博弈对象，从来不是<对手>，而是<你自己>。

## 11. 标题公式

- 正向钩：`<N> 个 <主题> 细节，让你 <能力>，<痛点消除>，<收益>。`
- 禁忌钩：`分享 <N> 条肮脏至极的 <主题> 心机。`
- 拆信条钩：`<全民信条>，是骗了你 <N> 年的一句话。`
