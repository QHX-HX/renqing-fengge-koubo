# renqing-fengge-koubo

钱多多的口播文案风格生成器（WorkBuddy / CodeBuddy 的 user skill）。

融合「人情世故博主」的清单体 × 一物一喻 × 设问轰炸 × 数字铁律 × 双轨读心 × 反直觉反转 × 玄学升华 × 留白梗，与钱多多原有的悬念递进 /「品品」式反讽 / 删除线 / 金句收束风格。

## 这是什么

给它一个主题（尤其博弈论系列），它套用固定风格公式生成口播文案：

> 标题钩 → 编号清单体 → 每条四段式 → 升华条 → 金句收尾

## 安装

把整个目录复制到你的 user skills 目录：

- Windows：`C:\Users\<你>\.workbuddy\skills\renqing-fengge-koubo\`

## 使用

- 「按人情世故博主风格写第 3 期」
- 「把这主题套进清单体 / 一物一喻 / 数字铁律风格」
- 「生成一篇 XX 主题的口播稿」
